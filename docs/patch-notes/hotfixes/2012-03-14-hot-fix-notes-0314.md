# Hot Fix Notes - 03/14

Official Mythic hot fix notes, published 2012-03-14.
Retrieved from the Internet Archive capture of
`http://www.warhammeronline.com/article/Hot-Fix-Notes-0314`.
Converted from HTML to plain text; wording, ordering and spelling are unchanged.

We have applied the following fix to all servers today:

- Corrected an issue where loot and world objects specific to the Night of Murder event were inadvertently reactivated.

- Fixed an issue where Heroic Defender was being applied at the Fortresses. This was not intended, and has been removed.
