# Additional Fixes - 02/02

Official Mythic hot fix notes, published 2012-02-02.
Retrieved from the Internet Archive capture of
`http://www.warhammeronline.com/article/Additional-Fixes-0202`.
Converted from HTML to plain text; wording, ordering and spelling are unchanged.

We used the maintenance to apply the following correctives:

- Fixed an issue that was causing players to be sent to the wrong location when attempting to engage in the Hunter’s Vale Dungeon in Tier 1.

- Fixed an issue that was allowing players with the relic to be summoned, queue, or the like. Players should not be able to move with the relic via these methods now.

- Added missing messaging and localization files.
