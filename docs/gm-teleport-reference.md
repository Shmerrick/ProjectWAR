# GM teleport reference

Command prefix is `.` (`BaseCommands.cs:69`). Teleport requires `EGmLevel.GM`;
turn GM mode on with `.gm on` if a command is rejected.

```
.teleport map <ZoneId> <X> <Y> <Z>
.teleport objective <ObjectiveId>
```

## Kill Collectors

`Go to mobs` is the average position of that collector's target creatures, which is
where you need to be to earn credit. Kill there first, then talk to the collector -
progress is retroactive.

Four collectors have no targets in ProjectWAR's data and can never pay out; they are
marked *(no targets)*.
