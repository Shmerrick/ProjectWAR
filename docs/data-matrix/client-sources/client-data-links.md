# Client data links

Columns whose values resolve into another file's key. Generated by
`ClientDataMatrix report sources`; do not edit by hand.

## Read this before using the table

**These are leads, not conclusions**, and the numbers alone cannot tell you which.

Most of these files number their rows from 1 with no gaps. Any column of numbers that
falls inside such a range resolves into it completely, whether or not it means to, so a
100% rate against a dense target is worth nothing on its own. That is what the **target
density** column is for: at 100% the target is a contiguous run of ids and the match is
free; the lower it goes, the more the match had to earn.

Rows are ordered by how surprising the match is rather than by rate, so the top of the
table is the part worth reading.

The **sample** column is what actually settles it. Nothing about 88,676 item rows
resolving into `objects.csv` proves `ModelId` means art -- what proves it is that 8334 is
named `tk_soultalisman_intelligence` and the item carrying it grants Intelligence. Read
the names, not the percentages.

And the standing warning: `data/gamedata/abilities.csv` agrees with the client's real
ability ids on 13 of 3,115 while looking entirely plausible by these measures. Joining on
it is what filled `mythic_src_abilities` with another ability's names and effect ids.

Thresholds: at least 50 distinct values, at least 90% resolving. Column 0 is never treated as a source, being the row id in these files.
